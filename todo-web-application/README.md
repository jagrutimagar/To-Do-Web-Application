# Todo Web Application

A simple todo application built with Node.js, Express, and vanilla JavaScript.

## Features

- Add tasks
- Mark tasks as complete or incomplete
- Remove tasks
- Persist tasks in a JSON file

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the application:
   ```bash
   npm start
   ```
3. Open your browser at:
   ```text
   http://localhost:3000
   ```
